# GameMode1

一个基于 Unity 和 C# 开发的 2D 横版动作游戏学习项目，围绕角色控制、战斗交互、Boss 行为和场景 UI 等内容进行实践。

## 开发环境

- **引擎版本**：2022.3.44f1c1
- **开发语言**：C#
- **游戏类型**：2D 横版动作

建议使用与项目一致的编辑器版本，避免因版本差异导致资源或配置兼容问题。

## 主要功能

### 角色控制

包含移动、跳跃、空中运动、冲刺、滑墙和蹬墙跳等动作。通过状态机组织角色行为，将待机、移动、跳跃和攻击等逻辑拆分为独立状态，便于理解与扩展。

### 战斗与动画

包含角色普通攻击逻辑，并通过动画事件连接动作播放与游戏逻辑。角色和 Boss 分别维护对应的动画事件处理脚本。

### Boss 行为

实现了骷髅 Boss 的状态机，包含待机、移动、战斗、普通攻击和尖刺攻击等状态，用于练习敌人行为切换与攻击流程。

### 场景与界面

项目包含主菜单、主场景、Boss 场景及测试场景，同时提供菜单与 UI 相关脚本。

## 项目结构

| 路径 | 内容 |
| --- | --- |
| `Assets/Scripts/Player` | 角色控制、状态机与动画事件 |
| `Assets/Scripts/Boss` | Boss 行为、状态机与攻击逻辑 |
| `Assets/Scripts/Abstract` | 实体与特效相关的基础类 |
| `Assets/Scripts/UI` | 主菜单与界面逻辑 |
| `Assets/Scenes` | 主菜单与游戏场景 |
| `Assets/Animation` | 动画与动画控制器 |
| `Packages` | 项目依赖配置 |
| `ProjectSettings` | 编辑器与项目设置 |
